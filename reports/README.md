# Reports

Place progress notes, contribution evidence and the final report here. The final PDF will be generated from actual experiments. Record each member's work and contribution percentage after the group agrees on the method and checks the instructor's guidance.

Start with [the report template](final_report_template.md) and [review checklist](review_checklist.md).
Keep all benchmark numbers traceable to real experiment outputs. The template is
not the final report; `package_submission.py --final` requires `final_report.pdf`.
